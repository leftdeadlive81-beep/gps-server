📖 1. このアプリについて

「現在位置自動共有君（Puttan）」は、 複数のユーザーの現在位置や活動状況などを リアルタイムで共有するために開発している 情報共有アプリです。

地図上でユーザーの位置を確認できるほか、 UTM座標、地点登録、クロノロジー、 交通規制情報などの機能を利用できます。

現在の位置付け
本アプリは現在も開発・改良中の 実験アプリケーションです。

👤 3. ユーザー登録

アプリを使用する際に、自分のユーザー情報を登録します。

登録できる主な情報

  • 名前
  • 現在位置
  • 水分量
  • 燃料
  • 目的地
  • アイコン
ポイント
登録されたユーザー情報はサーバーを経由して、 接続している他の端末にも共有されます。
```
```

📍 4. GPS現在位置共有

スマートフォンなどのGPS機能を利用して、 ユーザーの現在位置を取得します。

取得した位置情報はサーバーへ送信され、 接続中の端末へリアルタイムに共有されます。

🛰 表示される主な情報

  • ユーザー名
  • 現在位置
  • アイコン
  • UTM座標
  • 水分量
  • 燃料
  • 目的地
  • 最終更新時刻
注意
GPSの精度や更新状況は、 端末の設定、衛星の受信状況、通信環境、 省電力設定などによって変化します。
```
```

🗺 5. 地図

登録されたユーザーや地点などを 地図上で確認できます。

用途に応じて複数の地図を切り替えて 使用できます。

🗺 利用できる地図

  • 🗺 標準地図
  • 🛰 航空写真
  • ⛰ 地形図
  • 🇯🇵 国土地理院
  • 🚒 防災淡色地図
```
```

🧭 6. UTM座標

GPSから取得した現在位置を、 UTM座標として表示できます。

項目 内容
UTM Zone UTMゾーン
E 東距（Easting）
N 北距（Northing）

緯度・経度だけでなく、 UTM座標を利用した位置確認や情報共有が可能です。

```
```

📌 7. 地点登録

地図上の任意の場所を「地点」として登録できます。

登録できる情報

  • 地点名
  • 地点種類
  • 緯度
  • 経度
登録された地点はサーバーに保存され、 接続している端末へ共有されます。
```
```

📜 8. クロノロジー

活動状況や連絡事項などを時系列で記録・共有する機能です。

新しいメッセージが上に表示されます。

保存件数

サーバーには最大100件のクロノロジーが保存されます。

アプリを再起動した場合でも、 保存されているクロノロジーを復元できます。

```
```

🚧 9. 交通規制情報

国土交通省が提供する道路関連GISデータを利用して、 熊本県内の交通規制情報を取得します。

🔄 自動更新

  • アプリ起動時に最新データを確認
  • その後、3日ごとに自動更新
  • 更新された情報を接続中の端末へ共有
交通規制情報は、 国土交通省GISデータを元にしています。
重要
交通規制情報にはデータ更新までの時間差が 発生する場合があります。 実際の通行可否を判断する場合は、 現地の標識、係員、その他の公式情報も 必ず確認してください。
```
```

👥 10. ユーザー一覧

現在登録されているユーザーを確認できます。

ユーザーごとに、位置情報や状態などを 確認できます。

確認できる主な情報

  • ユーザー名
  • アイコン
  • 現在位置
  • 水分
  • 燃料
  • 目的地
  • 最終更新時刻
```
```

🗑 11. ユーザー削除

不要になったユーザー情報を削除できます。

ユーザーを削除すると、 サーバー上の現在ユーザー情報からも削除され、 接続中の端末へ変更内容が通知されます。

ユーザー削除を行う際は、 削除対象を十分に確認してください。
```
```

🗑 12. 地点削除

登録済みの地点を削除できます。

地点を削除すると、 サーバー上の地点情報も削除され、 接続中の端末へ変更内容が反映されます。

```
```

🔄 13. リアルタイム共有

PuttanではSocket.IOを利用して、 サーバーと接続中の端末間で情報を リアルタイムに共有します。

共有される主な情報

  • ユーザー位置
  • ユーザー登録情報
  • 地点情報
  • クロノロジー
  • 交通規制情報
リアルタイム連携
ある端末で情報が更新されると、 接続中の他の端末にも自動的に反映されます。
```
```

💾 14. データ保存

PuttanではPostgreSQLを利用して、 必要な情報をサーバー側に保存しています。

保存される主な情報

  • ユーザー情報
  • 位置情報・位置履歴
  • 登録地点
  • クロノロジー
  • その他アプリケーションデータ

データベースにはSupabase上の PostgreSQLを利用しています。

```
```

⚠️ 15. ご利用上の注意

  • GPSの位置情報には誤差があります。
  • 通信環境によって情報の更新が遅れる場合があります。
  • 端末の省電力機能などによって GPS更新が制限される場合があります。
  • 交通規制情報には更新までの時間差が 発生する場合があります。
  • 重要な判断を行う場合は、 現地の状況や公式情報も確認してください。
  • 現在のWeb版では、 スマートフォンの画面がOFFになった場合、 GPS情報の更新が停止する場合があります。
今後の改善予定
スマートフォン向けアプリ版では、 バックグラウンドでのGPS取得など、 Web版よりも安定した位置情報取得を 実現することを目標としています。
```
```
